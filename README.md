# DOUBLE B · المنيو الرسمي

موقع منيو رسمي **ثابت** (static) لزبائن Double B Cafe — أبها · خدمة الدرايف-ثرو.

هذا المستودع **مستقل تمامًا** عن لوحة التدقيق الداخلي في Manus: لا تسجيل دخول، ولا قاعدة بيانات،
ولا تقييمات صور، ولا ملاحظات فريق، ولا أي رابط خاص أو داخلي. كل شيء يُقدَّم للزائر هو صفحة واحدة
+ صور مستضافة داخل المستودع نفسه.

- **الموقع:** https://ispada88-op.github.io/doubleb-official-menu/
- **المستودع:** https://github.com/ispada88-op/doubleb-official-menu

## البنية

```
index.html              الصفحة كاملة (تصميم + بيانات المنيو مدمجة داخلها)
assets/logo-bb.png      شعار DOUBLE B
assets/img/*.webp       صور الأصناف (web-optimized) + logo
assets/img/_map.csv     جدول ربط: اسم الصنف ← ملف الصورة (مرجع التحديثات)
assets/menu-data.json   نسخة JSON من بيانات الأصناف (مرجع/تدقيق)
menu.csv                المصدر المعتمد للأصناف (القسم، الصنف، الوصف، الحجم، السعر، الصورة)
combos.csv              المصدر المعتمد للكومبوهات
tools/build-from-csv.py يعيد توليد بيانات الصفحة من menu.csv + combos.csv
```

## كيف يعمل الموقع

`index.html` يحتوي على الأقسام والتصميم (HTML + CSS)، وبيانات الأصناف والكومبوهات مدمجة في
سطر واحد اسمه `const FALLBACK = {...}` داخل الصفحة. الصفحة لا تجلب أي بيانات من الإنترنت
(`MENU_SHEET` و`COMBOS_SHEET` فارغة) — لذلك تعمل بدون إنترنت ولا تعتمد على خدمات خارجية.

الصور تُقرأ من `assets/img/`، والشعار من `assets/logo-bb.png` — كلها داخل المستودع.

## تحديث الأسعار أو الأصناف

1. عدّل `menu.csv` (و/أو `combos.csv`). الأعمدة المعتمدة:
   `القسم, الصنف, Item, الوصف, الحجم, السعر, شارة, الصورة, ظاهر`
   - الصفوف التي `ظاهر = لا` لا تظهر للزبون.
   - سطر لكل حجم: صنف بمقاسين = صفان (الحجم `S` و`L`).
2. شغّل:

   ```bash
   python tools/build-from-csv.py
   ```

   يعيد كتابة `const FALLBACK` داخل `index.html` من الملفات، ويربط كل صنف بصورته من
   `assets/img/_map.csv`.
3. أضف صورة جديدة (اختياري): ضعها في `assets/img/` بصيغة `.webp`، وأضف سطرًا في
   `assets/img/_map.csv` باسم الصنف واسم الملف.
4. ارفع التغييرات:

   ```bash
   git add -A && git commit -m "تحديث المنيو" && git push
   ```

   GitHub Pages يعيد النشر تلقائيًا خلال ~دقيقة على الرابط أعلاه.

## النشر (GitHub Pages)

- المصدر: فرع `main`، المجلد `/` (الجذر).
- لا يحتاج أي إعدادات بناء؛ الملفات جاهزة كما هي.
- لتغيير مصدر الصفحات: Settings → Pages → Branch: `main` / `(root)`.
